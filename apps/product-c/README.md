# Riverside Books — Product C

Customer support chatbot for Riverside Books.

## What this app does

- answers common bookstore support questions
- covers pickup, delivery, store hours, returns, and exchanges
- suggests popular customer questions
- uses a simple static HTML/CSS/JS setup

## Local preview

From this folder, run:

```bash
python3 -m http.server 8001
```

Then open:

```text
http://localhost:8001
```

## Notes

This is a standalone prototype for Product C and matches the approved Riverside Bookstore project direction for a lightweight support chatbot.
